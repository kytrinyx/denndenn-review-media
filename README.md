# DennDenn Review Media

DennDenn is a practice app for K-pop random play dance that runs on iPhone and iPad.

It takes the songs you know well enough to dance at full speed and plays them back to back in random order, with a countdown before each one. While you're still working on a song, you can play it by itself, slow it down, or have it repeat.

The app ships without any media. In order to make it easier for Apple's team to review, I'm providing two synthetic videos optimized to demonstrate the app's features.
